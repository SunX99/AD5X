## Installing a full firmware on AD5X

> ### The installation takes a lot of time up to an hour.

**Download to a flash drive**  
⦁ AD5X-factory-1.0.9.tgz  
⦁ AD5X-factory.tar.xz

1.  Format the USB Flash to FAT/FAT16/FAT32
2.  Place the file(s) in the root folder of the USB Flash
3.  Turn off the printer
4.  Insert the flash drive into the printer
5.  Turn on the printer

⦁ After the update, if you need to reflash the MCU, install AD5X Official tgz
